Folio · Design v1 · Modern & Sharp

Books you
actually own.

A reader for the EPUBs already on your device — no accounts, no cloud, no expiry. Folio stays out of the way. The chrome disappears, the type breathes, and every interaction is built around one feeling: you opened a book and it just started.

01
Ownership over access If you imported it, it stays. Local files, local progress, local highlights. No login wall, no DRM, no "available in your region."
02
Type-first, chrome-last The reader is a page, not a UI. Controls fade out within 1.5s of opening a book and only return on a center tap.
03
Fluid by default 60fps page turns, predictive chapter pre-render, instant theme switching. Performance is a design property, not an optimisation.

06 · ANNOTATIONS
Highlights, on their own terms
Three colours by intent — amber = important, green = connection, yellow = "look up later". Tap a card to jump back to the exact paragraph (we already store `chapterIndex` + `scrollFraction` per Bookmark).

What this means for the build

Maps to existing Folio code

Reading experience ReaderView

The "1.5s auto-hide chrome" is the headline interaction. It's just a Task.sleep + an @Observable bool. Pre-render the next chapter's HTML into a second WKWebView as soon as the user passes 80% of the current chapter — page-turn cost drops from ~120ms to under one frame.

Library & organisation LibraryView

"Continue reading" hero card pulls the most-recent Book with a non-nil progress. Sort default stays addedDate. New: a "Reading" filter pill (progress != nil && progressFraction < 1) and "Finished" (progressFraction == 1) — both derived, no schema change.

Ownership story BookStoring

The amber "Yours forever" card needs no new code — it surfaces what's already true: BookStore copies files into the app's local container and never phones home. Make this visible: show file path, size, and an "Export EPUB" action that uses UIDocumentPickerViewController.

Annotations Bookmark

Today Bookmark has note: String? but no colour/tag. Smallest extension: add kind: BookmarkKind (.important / .connection / .lookup) with a default that backfills existing rows. The Notes screen groups by book and is reachable from the tab bar — not buried inside the reader.

Typography sheet SettingsViewModel

Reuse the existing EPUBStylesheet bindings — font, fontSize (12–26), lineSpacing (1.2–2.2), theme. New control: margin width (a 3-stop segmented: tight / comfortable / wide) that maps to a CSS variable injected on chapter load. Persist via the existing UserDefaults pipe.

Motion & perf cross-cutting

Three motion primitives: 180ms ease-out for chrome reveal, 320ms cubic-bezier(.3,0,.2,1) for page turns, 380ms spring for sheets. Theme switch is instant (no fade) — switching mid-page should feel like turning on a lamp, not loading a new screen.
